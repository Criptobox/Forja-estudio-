# FORJA Studio — Preview mobile-first v0.1

Este ZIP conserva íntegramente el proyecto Estilos recibido y añade un prototipo frontend real de FORJA Studio en `web/forja.html`. No utiliza la imagen de referencia como fondo ni como pantalla: las pantallas se construyen con HTML, CSS y JavaScript.

## Abrir
Abre `web/forja.html` localmente o visita `https://TU_USUARIO.github.io/TU_REPO/web/forja.html` después de publicar GitHub Pages.

## Incluye 12 vistas
Bienvenida, inicio, agente conversacional, progreso, resultado, lista de pantallas, editor, componentes, estilos, preview responsive, proyectos, biblioteca/diseños y exportación.

## Interacciones implementadas
Navegación inferior, plantillas rápidas, flujo de creación simulado, pantallas y componentes seleccionables, búsqueda de componentes, paletas/temas, selección de dispositivo y selección de formato de exportación.

## Importante
Es un prototipo funcional de interfaz. El agente LLM, voz, navegador autónomo, exportación real y guardado persistente todavía no están conectados. Las acciones pendientes informan claramente que requieren backend.

## Identidad visual
Fondo carbón `#100F18`, superficies `#1A1925` y `#242230`, naranja `#FF790D`, violeta `#8E38FF`, tarjetas redondeadas, brillos sutiles, tipografía Plus Jakarta Sans y navegación inferior táctil.
