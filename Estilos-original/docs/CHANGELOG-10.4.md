# Estilos 10.4 — Edición de texto directa

- Nuevo modo Texto accesible desde la barra inferior y el encabezado del lienzo.
- En modo Texto, toca un texto dentro de un componente para editarlo directamente.
- Los cambios se guardan en la capa correspondiente y se restauran al volver a abrir el proyecto.
- Los textos editados también se incorporan al HTML exportado.
- Se conservan estilos, estructura y contenido no editado.
- Los componentes basados en código aislado (iframe) no admiten esta edición directa.
