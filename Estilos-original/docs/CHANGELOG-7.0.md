# Estilos 7.0

## Biblioteca personal
- Favoritos persistentes para componentes de la biblioteca.
- Búsqueda por nombre y filtros de categoría.
- Colecciones personalizadas creadas por el usuario.
- Guardado de la capa seleccionada como componente reutilizable.
- Inserción de componentes guardados en cualquier pantalla.
- Almacenamiento local para favoritos, colecciones y componentes personales.
- Límite de 30 capas por pantalla.

## Validación
- Sintaxis JavaScript del constructor y service worker validada.
- ZIP verificado.
- APK no compilado ni probado en dispositivo físico.
