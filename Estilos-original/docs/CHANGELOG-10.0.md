# Estilos 10.0 — Selector visual de diseños

- La biblioteca del constructor deja de usar menús desplegables con nombres solamente.
- Cada diseño se presenta como tarjeta con miniatura generada desde su vista previa real, nombre y categoría.
- Categorías desplegables para explorar sin saturar toda la pantalla.
- Buscador para filtrar por nombre o categoría.
- Tocar una tarjeta añade el diseño a las capas de la pantalla actual.
- Se conserva el límite de doce componentes, la edición de capas, las pantallas y la exportación.
- No se declara APK compilada ni prueba física Android.
