# Estilos 8.0

- Estudio de recursos por categorías: avatares, iconos, ilustraciones, fondos y animados.
- 20 recursos visuales listos para insertar como capas editables.
- Seis paletas aplicables al proyecto y a la capa activa.
- Selector de color personalizado.
- Importación de PNG, JPG, WEBP y SVG de hasta 1 MB.
- Animaciones CSS sutiles en recursos de movimiento.
- Validación JavaScript y ZIP; APK no compilado ni probado en dispositivo.
