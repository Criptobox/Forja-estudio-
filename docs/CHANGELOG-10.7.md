# Estilos 10.7 — Grupos y carpetas de capas

- Carpetas visuales para organizar las capas de una pantalla.
- Crear carpeta asignando la capa seleccionada.
- Mover componentes entre carpetas desde cada fila.
- Renombrar carpetas y actualizar todas sus capas.
- Plegar y desplegar carpetas para reducir el desorden.
- Eliminar carpetas sin borrar sus componentes: vuelven a quedar sin carpeta.
- Se mantienen selección, miniaturas, visibilidad, bloqueo, duplicación, eliminación y reordenamiento.
- La agrupación se guarda dentro de los datos de cada capa.
