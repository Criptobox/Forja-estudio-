# Estilos 10.8 — Deshacer y rehacer

- Historial local de hasta 60 estados del constructor.
- Controles Deshacer y Rehacer dentro del panel de capas.
- Atajos Ctrl/Cmd+Z y Ctrl/Cmd+Y; Ctrl/Cmd+Shift+Z rehace.
- Captura previa a acciones de capas, pantallas, grupos, campos editables, imágenes y manipulación directa.
- Restauración del proyecto completo y guardado en almacenamiento local.
- Se mantienen las funciones de las versiones 10.0 a 10.7.
