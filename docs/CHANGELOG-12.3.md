# 12.3 · El creador arma la página entera

- Un proyecto nuevo empieza con la pantalla vacía: ya no trae cabecera («Descubrir más») ni barra inferior de ejemplo. Ambas se pueden activar en «Estructura de la página»; los proyectos antiguos las conservan.
- Cada elemento tiene una posición: **Arriba**, **Contenido** o **Abajo**. Las barras de la biblioteca se colocan abajo al añadirlas, y la barra de ejemplo se oculta sola.
- Los elementos nuevos se ven **sin tarjeta** (tal cual son, de borde a borde); «Con tarjeta» recupera fondo, borde, redondeo y sombra.
- Hasta 20 elementos por pantalla (antes 12).
- La exportación (HTML, React y Tailwind) respeta la cabecera opcional, el orden Arriba/Contenido/Abajo y los elementos sin tarjeta, y ajusta la altura de cada elemento a su contenido.
- Instalación como app: botón «Instalar la app» en Ajustes (12.2.1).
- 174 pruebas de extremo a extremo.
