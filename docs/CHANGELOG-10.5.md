# Estilos 10.5 — Reemplazo de imágenes en el lienzo

- Nuevo modo Imagen en la barra inferior y en el encabezado del lienzo.
- Toca una imagen, avatar, icono SVG o elemento con imagen de fondo para reemplazarlo.
- Abre el selector de imágenes del dispositivo.
- Procesa imágenes PNG/JPG/WebP de hasta 6 MB y las optimiza a WebP/JPEG para reducir almacenamiento.
- Los reemplazos se guardan por componente y se aplican en el preview y en el HTML exportado.
- Los elementos SVG seleccionados se sustituyen por la imagen elegida.
- Se limita el tamaño final de cada imagen para proteger el almacenamiento local.
