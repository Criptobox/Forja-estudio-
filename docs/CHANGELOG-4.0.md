# Estilos 4.0.0

## Constructor multipantalla
- Proyectos con hasta ocho pantallas independientes.
- Crear, duplicar, renombrar mediante edición del título y eliminar pantallas.
- Cada pantalla conserva sus componentes, orden y propiedades al cambiar de pestaña.
- Exportación HTML con navegación funcional entre pantallas.

## Editor avanzado por componente
- Tipografía: tamaño, peso y alineación.
- Fondo, color de texto, borde, grosor de borde, redondeo y espaciado.
- Ancho relativo, desplazamiento X/Y y sombra.
- Arrastre del asa en la vista previa (mouse y táctil) para ajustar desplazamiento.
- Duplicar, eliminar y reordenar sin perder la configuración.

## Temas reutilizables
- Presets Violeta Studio, Midnight, Ivory y Mint.
- Guardado local de temas personalizados.

## Compatibilidad
- Se conserva la clave de almacenamiento `estilos-builder-v1`.
- Las pantallas guardadas en 4.0 se incorporan a la estructura extendida; los proyectos anteriores se migran a una primera pantalla.
- Web/PWA 4.0.0; Android versionCode 11 / versionName 4.0.
- La compilación del APK debe confirmarse en GitHub Actions.
