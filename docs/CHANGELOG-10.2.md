# Estilos 10.2 — Constructor optimizado para móvil

- Navegación fija inferior con accesos a Vista, Editar y Biblioteca.
- Desplazamiento directo y suave a cada zona del constructor.
- En móvil, el lienzo aparece primero y ocupa el ancho disponible.
- Mejoras de tamaño táctil para pestañas, botones, controles y miniaturas.
- Selector de pantallas horizontal y compacto.
- Ajustes de espaciado, tarjetas y paneles para pantallas estrechas.
- En escritorio se conserva la distribución anterior.
