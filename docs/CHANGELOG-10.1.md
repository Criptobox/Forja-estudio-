# Estilos 10.1 — Colocación visual por arrastre

- Las miniaturas de la biblioteca ahora se pueden arrastrar.
- Soltar sobre el lienzo añade el diseño al final de la pantalla.
- Soltar sobre una capa inserta el componente en esa posición.
- Se mantiene el toque/clic para añadir desde móvil.
- Se conserva el reordenamiento de capas existente.
- Se mantiene el límite de doce componentes por pantalla.
