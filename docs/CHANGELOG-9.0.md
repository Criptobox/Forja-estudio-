# Estilos 9.0 — Component Studio

- Variantes visuales por componente: Clásica, Glass, Soft UI, Outline y Bold.
- Animaciones configurables: Fade, Rise, Zoom, Float y Pulse.
- Duración ajustable de 300 a 3000 ms.
- Control de elevación/sombra y estilo de borde.
- Presets de estilo de un toque.
- Nuevos estilos aplicados a la vista previa y a la exportación HTML.
- Sintaxis JS y service worker validados; ZIP íntegro.
- APK no compilado ni probado en dispositivo Android.
