# Estilos 10.3 — Edición táctil directa

- Cada bloque seleccionado muestra un control de movimiento y un control de tamaño.
- Arrastrar ⠿ mueve el componente directamente en el lienzo.
- Arrastrar ↘ ajusta ancho, espaciado interior y tamaño de fuente.
- Los cambios se guardan al soltar y actualizan las propiedades del componente.
- Los controles tienen objetivos táctiles ampliados en móvil.
- Se amplió el rango de desplazamiento del componente.
