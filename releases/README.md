# Archivo de entregas

Esta carpeta conserva snapshots históricos que no forman parte de la aplicación desplegada.

- `previews/`: HTML autónomos para consulta visual; no son el código fuente activo.
- `manifests/`: manifiestos versionados de entregas anteriores. El manifiesto canónico permanece en la raíz como `VERSION-ENTREGA.json`.

La aplicación activa está en `web/`; GitHub Pages publica exclusivamente esa carpeta.
