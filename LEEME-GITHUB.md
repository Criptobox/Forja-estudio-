# Publicar FORJA STUDIO v0.2

1. Crea un repositorio nuevo llamado `FORJA-STUDIO`.
2. Descomprime el ZIP.
3. Sube los archivos y carpetas directamente a la raíz (index.html, assets/, manifest.webmanifest y documentación).
4. Abre Settings → Pages.
5. Selecciona Deploy from a branch → `main` → `/ (root)` y guarda.
6. Espera a que GitHub Pages publique el sitio.

No lo mezcles con el repositorio Estilos/Tinta. Este proyecto es independiente.
