# FORJA STUDIO — v0.2 visual foundation

Proyecto independiente, construido desde cero y basado en la referencia visual compartida por el usuario.

## Ejecutar
Abre `index.html` en un navegador moderno. Para GitHub Pages, sube el contenido de esta carpeta a la raíz de un repositorio nuevo y activa Pages desde `main` → `/ (root)`.

## 12 pantallas incluidas
1. Bienvenida
2. Inicio / creación
3. Agente conversacional
4. Progreso
5. Resultado
6. Pantallas del proyecto
7. Editor visual
8. Biblioteca de componentes
9. Personalización de estilo
10. Preview responsive
11. Mis proyectos
12. Exportación

## Editor visual v0.4
Los componentes elegidos en la biblioteca se insertan en el lienzo del editor. Se pueden seleccionar, subir de posición, duplicar, renombrar y eliminar. La composición se guarda localmente en el navegador y sus elementos añadidos también aparecen en la vista previa.

## Biblioteca de diseño v0.3
24 componentes visuales diferenciados en tarjetas, botones, navegación, banners, formularios y datos. Incluye búsqueda, filtros por categoría, favoritos guardados localmente, ficha de detalle y acción para añadir al proyecto.

## Interacciones actuales
Navegación entre vistas, selección de plantillas, flujo de creación simulado, mensajes locales, selección de componentes, temas, radio de esquinas y descarga de un HTML de muestra.

## Límites transparentes
Esta versión es la base visual navegable. El agente todavía no usa un modelo IA, el progreso es simulado, el guardado no es persistente y la exportación no genera aún un proyecto React completo. Esas capacidades se implementarán en fases posteriores.
